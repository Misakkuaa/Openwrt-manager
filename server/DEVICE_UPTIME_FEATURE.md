# 设备在线时长功能说明

## 🎯 新增功能概述

为OpenWrt设备管理系统添加了全面的设备在线时长监控功能，让用户可以清晰地了解设备的连接历史和当前状态。

## ✨ 核心功能

### 1. 设备在线时长计算
- **总存在时长**: 从设备首次连接到当前时间的总时长
- **当前会话时长**: 设备当前连续在线的时长
- **离线时长**: 设备离线后到现在的时长
- **心跳间隔**: 距离上次心跳的精确时间

### 2. 智能时长格式化
- 自动选择合适的时间单位（秒、分钟、小时、天、年）
- 最多显示两个时间单位，避免信息过载
- 支持中文时间格式显示

### 3. 设备详情页面
- 突出显示当前在线时长
- 完整的设备连接历史
- 实时状态监控
- 自动刷新功能

## 📈 计算逻辑

### 1. 在线状态判断
```
设备在线 = 上次心跳时间 <= 当前时间 - 120秒
```

### 2. 总存在时长
```
总时长 = 当前时间 - 首次连接时间
```

### 3. 当前会话时长
```
如果设备在线:
    会话时长 = 当前时间 - 最后离线时间
    (简化实现：当前时间 - 首次连接时间)
如果设备离线:
    会话时长 = 0
```

### 4. 时长格式化规则
- 不足1分钟：显示秒数
- 不足1小时：显示分钟和秒数
- 不足1天：显示小时和分钟
- 超过1天：显示天数和小时
- 超过1年：显示年数和天数
